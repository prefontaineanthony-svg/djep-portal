# DJEP portal backups

Copies of what is saved inside DJEP, so nothing is lost if a settings box gets wiped.

Where these live in DJEP: Website Tools > Client Portal > Appearance
(websitetools_client_portal.asp?action=edit_client_logon_appearance)

| File | DJEP field |
| --- | --- |
| portal-custom-scripting.html | Custom Scripting Code (the main portal script, ends with the djep-extras.js loader) |
| portal-welcome-text.html | Default Welcome Text |
| portal-planner-only-welcome-text.html | Planner Only Welcome Text |

To restore: open the file here, copy everything, paste it into the matching DJEP box, and click Save.
